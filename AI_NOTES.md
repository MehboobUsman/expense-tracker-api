# AI Usage Notes

## AI Tool Used

- ChatGPT (OpenAI)

## 1. AI-Generated vs. My Work

AI was used to provide guidance, explain concepts, suggest code structure, and help debug issues.

I personally implemented and integrated the project by:

- Creating the project structure
- Writing and organizing the Express routes and controllers
- Implementing the expense model and in-memory data storage
- Connecting the frontend (HTML, CSS, JavaScript) with the backend
- Writing and modifying code based on my project requirements
- Running the application and fixing errors during development

## 2. What I Validated, Tested, or Changed

I reviewed and tested all AI-generated suggestions before including them in the project.

I validated:

- API endpoints using Postman
- Frontend functionality in the browser
- Jest and Supertest test cases
- CRUD operations (Create, Read, Update, Delete)
- Expense filtering
- Total expense calculations
- Swagger API documentation

During development I also corrected several issues, including:

- Module import and file path errors
- Variable naming mistakes
- Test failures after introducing the frontend
- Route and controller updates
- Frontend integration with the REST API

## 3. AI Suggestions Not Used

Some AI suggestions were intentionally not included:

- Database integration (MongoDB), because the assignment specified that a database was not required.
- Docker support, because I chose Swagger as the optional bonus feature.
- Additional features beyond the assignment requirements, keeping the project focused and aligned with the specification.

## Summary

AI was used as a development assistant for learning, debugging, and implementation guidance. Every feature included in the final submission was reviewed, tested, and verified before submission.
